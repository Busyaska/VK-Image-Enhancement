# VK Image Enhancement

Веб-приложение улучшения изображения по следующим параметрам: яркость, контрастность и цветность - посредством запуска в браузере пользователя ML-модели.

## Работа

Поддерживаемые форматы изображений: JPG, PNG, BMP и HEIC/HEIF (для HEIC приложение автоматически преобразует файл в PNG в браузере). Максимальный размер изображения - 15 Мпк.

Веб-приложение доступно по [ссылке](https://busyaska.github.io/VK-Image-Enhancement/).

## Запуск

Требования:
- Node.js 20 или новее.

### Локальный запуск
```bash
npm install
npm run dev
```
Веб-приложение будет доступно по ссылке: <code>http://localhost:5173</code>.

### Production сборка
```bash
npm run build
```
\- результат будет в `dist`.

## Обучение ML-модели
### Основные инструменты, используемые для обучения ML-модели:
- pytorch-cuda,
- scikit-image,
- scikit-learn.
### Датасет
В качестве обучающего набора данных использовался [MIT-Adobe 5K Dataset](https://www.kaggle.com/datasets/weipengzhang/adobe-fivek) с использованием ретушированных изображений эксперта C.
### План работы:
1) Изначальной целью стало определение параметров, которые применил эксперт к raw изображению. Для этого были сравнены два способа:
    - Независимая статистическая оценка (вычисление отношений mean/std пиксельных значений),
    - Совместная оптимизация (максимизация SSIM метрики).

    Совместная оптимизация продемонстрировала лучшее качество, поэтому ее значения в дальнейшем были взяты за основу.
2) Визуальное сравнение улучшенных изображений на основе значений, полученных благодаря совместной оптимизации, показала недостатончно высокую точность данного метода для использования вычисленных данных в качестве целевых значений для обучения модели, поэтому было принято решения создать обучающуюю выборку синтетически путем через ухудшение изображений эксперта. Для избавления от возможных выбросов было принято решения взять значения от 2 до 98 персентелей, таким образом сохранив 90% от изначальной выборки. Посколько оптимизация проводилась совместно для всех интересующих параметров, то было принято решение создать 2 датасета для проведения сравнительного эксперимента:
    - Выбор случайных параметров ухудшения в диапазоне от минимального до максимального вычисленных значений параметра,
    - Bootstrap выборка возможных троек значений, чтобы избежать случаев невозможных комбинаций.
3) В качестве модели была выбрана измененная архитектура [CSRNet](https://github.com/hejingwenhejingwen/CSRNet), разработанная для ретуши изображений, что является смежной с моей задачей.
4) После проведения двух экспериметов обучения моделей результаты оценивания были такие:
    >**PSNR** (Peak Signal-to-Noise Ratio) — это математическая метрика для оценки качества сжатия или искажения изображений, измеряемая в децибелах (дБ) и опирающаяся на среднеквадратичную ошибку (MSE). Главная её особенность — чем выше числовое значение PSNR, тем меньше искажений внесло сжатие или обработка, и тем ближе картинка к оригиналу.<br>
    >**SSIM** (индекс структурного сходства) — это метод оценки качества изображений, который измеряет схожесть двух картинок по трем признакам: яркость, контраст и структура. Он показывает, насколько сильно изменен или сжат снимок по сравнению с эталоном, и лучше отражает восприятие человеческого глаза, чем простые математические ошибки.<br>
    >**Delta E** (Δ E) — это стандартная метрика для измерения разницы между двумя цветами, определяющая точность цветопередачи. Она показывает расстояние между эталонным и реальным цветом в специальном цветовом пространстве (обычно CIELAB).

    | Метрика | Synthetic Dataset | Synthetic bootstrap Dataset | 
    | --- | --- | --- |
    | PSNR | 19.42 | 24.17 |
    | SSIM | 0.82 | 0.89 |
    | DELTA E | 10.07 | 6.04 |

    Модель, обученная на наборе данных, сгенерированным с использованием bootstrap метода, оказалась лучше по всем метрикам схожести изображений по сравнению с моделью, обученной на наборе данных, полученном путем выбора случайных параметров, поэтому в веб-приложении использовалась именно она.
5) Для корректной работы в браузере модель была конвертирована в формат ONNX.
